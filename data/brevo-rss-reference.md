## Why Brevo only showed 4 example keys in the preview

In Brevo's RSS setup window, under **Name of keys**, Brevo displays:

> *"You will be able to call rss tags from the channel and from an item. Each key has the same name than the tag."*
>
> *To call the `<title>` from channel, write: `{feed.TITLE}`*  
> *To call the `<pubDate>` from channel, write: `{feed.PUBDATE}`*  
> *To call the `<title>` from an item, write: `{item.TITLE}`*  
> *To call the `<pubDate>` from an item, write: `{item.PUBDATE}`*

Brevo **only lists `<title>` and `<pubDate>` as examples** to explain the syntax rule (*"Each key has the same name than the tag"*). It is not an exhaustive list.

Because our XML feed contains `<description>`, the corresponding key is:
- **`{item.DESCRIPTION}`** in single-brace contexts (like subject lines)
- **`{{ item.DESCRIPTION | safe }}`** inside Brevo's template body editor (the `| safe` filter tells Brevo to render the HTML markup rather than raw code).

## Two Ways to Run Hands-Off Weekly Emails

### Option 1: App Server Auto-Pilot (Recommended — Zero Brevo Template Needed)
You do not need to configure any templates or RSS keys in Brevo.
- The app's server (`node-cron`) is already running.
- Every **Monday at 8:00 AM EST**, it compiles the HTML digest and broadcasts it via your Brevo API key to your subscriber list automatically.
- You can test it anytime in the **Weekly Newsletter** modal → **Send Test to My Inbox**.

### Option 2: Brevo RSS Campaign
If you prefer Brevo to pull the RSS feed directly:
1. In Brevo: **Integrations** → **RSS Campaign**.
2. Paste the Feed URL: `https://ais-pre-sprjbzhbr2yqk7p72joffe-823764920969.us-east1.run.app/api/newsletter/feed.xml`
3. In the email template editor, add an **HTML block** or **Text block** and insert:
   ```html
   {{ item.DESCRIPTION | safe }}
   ```
4. For Subject Line, write:
   ```
   {item.TITLE}
   ```
